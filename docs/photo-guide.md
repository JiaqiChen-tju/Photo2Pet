# 照片怎么准备

`make_pet.py` 是"一张正面照 → 整套素材"的思路，它不接生成模型，所以**输入质量基本决定输出质量**。下面是最省事的准备方式。

## 一句话结论

> 纯色背景（首选白色）、单个主体、全身完整不裁切、正面朝前、图片短边 ≥ 400px。

## 推荐的照片

| 项目 | 建议 | 原因 |
|------|------|------|
| 背景 | 纯白或纯色，无渐变、无阴影、无杂物 | 抠图靠"从画布边缘泛洪清背景"，白底最可靠 |
| 主体 | 只有你要的角色，没有第二个人/道具 | 主体不唯一时抠出来的包围盒会歪 |
| 构图 | 全身入镜，头顶、脚尖都留一点空白 | 归一化按包围盒缩放，被裁掉的脚会被当成没有脚 |
| 朝向 | 正面直立，手臂自然下垂或稍微张开 | 侧视/背视是镜像 + 压缩 + 轻微旋转近似生成 |
| 尺寸 | 短边 400px 以上，最长边别超过 2000px | 太小会糊，太大只是慢 |
| 格式 | png / jpg / webp | 透明 png 也可以，用 `--cutout alpha` |

## 抠图三种模式怎么选

| 模式 | 适用 | 说明 |
|------|------|------|
| `auto`（默认） | 绝大多数情况 | 先判断是不是白底，是就走白底抠图，否则报错提示换模式 |
| `white` | 背景是白的，但图里白元素多到判不出来 | 强制按"近白=背景"处理 |
| `alpha` | 图片本身已经是透明背景（比如上一轮生成出来的精灵） | 直接使用 alpha 通道，不做任何抠图 |

命令行里换模式：

```bash
python make_pet.py --photo me.png --cutout white --name 我的桌宠
```

网页版里在「高级选项 → 抠图方式」里选。

## 已知的几个坑

1. **腿缝白条**：两条腿之间被鞋子/裙摆封住的白缝，泛洪进不去，会变成一块白色竖条。
   `make_pet.py` 会额外找"被前景包住的近白连通域"，短边小于图片短边 10% 的判为缝隙并清掉；
   宽大的白面（白裙子、白肚皮）不会被误删。
2. **粘连的手臂**：手臂贴住身体时，摆臂会让手臂和躯干一起变形，动作看起来"整体晃"。
   照片里手臂和身体之间有一点缝隙最好。
3. **极细长或极矮胖**：脚本用"25%~80% 高度内最宽的一行"当肩线、底部 8% 找双脚，
   对 2 头身大头和 6 头身细长都能用，但极端比例（比如纯长条）锚点会偏，建议换一张更接近人形的图。
4. **脖子几乎不存在**：宽体角色（绒毛怪这类）没有明显脖子，肩线会被判到很靠下的位置，
   这是"最宽行"启发式的正常行为，效果是摆臂从"腰"附近开始，通常反而更自然。

## 眼睛坐标（可选）

默认不做眨眼。想让桌宠眨眼，需要给两眼的坐标（像素，相对抠图后归一化的精灵图）：

```bash
python make_pet.py --photo me.png --eyes 70,120,130,120
```

四个数是 `x1,y1,x2,y2`：从图片左上角开始计数，X 向右、Y 向下；归一化后的图片高为 340 像素。
例如 `70,120,130,120` 表示左眼中心在 (70,120)，右眼中心在 (130,120)。
网页版在「高级选项 → 眼睛坐标」里填同样格式。生成的素材包中有 `sprite_preview.png`，
可以先生成并查看这张图，再照着像素位置填写并重新生成。不确定时留空即可，不影响桌宠生成。

## 校验生成结果

生成目录里有两张预览图，先看它们再决定要不要换照片：

- `preview.png`：舞蹈 16 帧拼图（动作是否破形、有没有白缝，一眼能看出来）
- `sprite_preview.png`：正面精灵本身（抠图边缘是否干净）

命令行跑完还会打印一段 JSON 报告，里面 `anchors` 是推断出来的肩线/双脚位置，
数值明显不合理（比如 `shoulder_y` 落在头顶）就说明这张图不适合自动推断。
