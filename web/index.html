一张照片，生成你的桌宠

上传一张正面、背景干净的图，这里会生成整套桌宠素材包（三视图 + 三档尺寸 + 舞蹈帧 + 预览），下载后配合桌宠程序即用。

点击选择图片，或把图拖到这里 支持 png / jpg / webp，建议白底、单主体、全身完整、不超过 20MB

每行一句，可填写任意数量；留空时桌宠不会随机弹出台词。
支持 PNG、JPG、WEBP、BMP；最多 20 张，每张不超过 20MB。
    高级选项

    眼睛坐标就是角色正面图上左眼、右眼中心的位置，填好后舞蹈时会眨眼。不设置也不影响生成。

    请看素材包里的 sprite_preview.png：从图片左上角开始，向右数是 X，向下数是 Y；图片高为 340 像素。格式为“左眼X,左眼Y,右眼X,右眼Y”。

    例如 70,120,130,120 表示左眼在 (70,120)、右眼在 (130,120)。不确定时留空即可；也可以先生成一次，看预览图再填写并重新生成。

    生成在本机完成，照片不会离开这台电脑。
    打包完成：下载素材包
    • 照片越干净越好：纯色（最好是白色）背景、主体居中、别被裁掉手脚。
    • 两条腿之间如果有白缝，会被自动清理；大面积白色身体不会被误删。
    • 表情图的文件名会成为右键菜单中的表情名称；启动桌宠后右键选择「切换表情」即可使用。
    • 怎么运行桌宠？先从项目 GitHub 页面的 Releases 下载并解压“Windows 便携版”；再把本次下载的素材包 ZIP 解压成文件夹，放到桌宠程序旁边；最后双击素材包文件夹里的“启动桌宠.bat”。不用输入命令。便携版尚未发布时，需要先运行项目源码中的桌宠程序。
