桌宠 - 使用说明

1. 双击压缩包中的桌宠 exe 即可运行（文件名随 GitHub 仓库名称变化）。
   不需要安装 Python，不需要安装 PySide6，不需要任何插件，
   不需要联网，不需要 API Key，不需要账号。

2. 建议放在桌面、文档等可写文件夹。
   首次运行会在 exe 同目录生成 config.json，用来记住位置、大小、模式。
   如果放在 C:\Program Files 等受保护目录，配置可能无法保存，建议移到可写目录。

3. 使用自己的角色：
   - 按 README.md「从源码运行」启动网页，上传角色照片并生成素材包。
   - 下载并解压 Windows 便携版；将素材包文件夹放到桌宠 exe 所在文件夹旁边。
   - 双击素材包中的「启动桌宠.bat」，即可用这套素材启动桌宠。
   - 如果还没有便携版，可在源码目录运行：
       .\.venv\Scripts\python.exe 桌宠.py --assets "素材包文件夹的完整路径"

4. 操作：
   - 左键单击：蹦跳并随机说一句（只有单击才会说话，待机、走路、跳舞都不出声）
   - 按住左键拖动：移动位置
   - 双击：打开喂食面板
   - 右键：模式 / 大小 / 切换表情 / 跳个舞 / 显示隐藏 / 鼠标穿透 / 置顶 / 开机自启 / 退出
   - 托盘图标右键：同款菜单；开启鼠标穿透后从这里解除
   - 默认待机/休息时会自动跳舞；右键「跳个舞」可手动跳一段
   - 切换表情时头顶会弹出大号气泡显示表情名称

5. 切换表情：
   右键 → 切换表情 → 选择表情文件名。
   选择后表情会锁定，走路不会覆盖；点「恢复默认」解除锁定。

6. 如果 SmartScreen 或杀毒软件拦截，请先确认程序来自项目的官方 GitHub Release，
   并核对发布页提供的 SHA-256 文件；不要仅凭提示就直接添加信任。
   PyInstaller 单文件程序有时会触发误报。
